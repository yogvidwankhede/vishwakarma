# Vishwakarma

Design intelligence for AI coding agents — one skill, 23 domains.

Install this plugin and "vishwakarma" appears as a single skill in your Claude Skills panel.
It covers UI generation, colour, motion, accessibility, components, tokens, layout, typography,
theming, SEO, performance, interaction design, scroll, surface, responsive, information
architecture, interface copy, states, micro-interactions, multiplayer games, and 3D assets.
