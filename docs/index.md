## Install in three seconds

In any Claude Code session:

```text
Install the skills from https://github.com/yogvidwankhede/vishwakarma
```

Claude fetches the compiled catalog and copies all 21 skills into your project. No commands, no build, no npm.

## Or use the plugin

```text
/plugin marketplace add yogvidwankhede/vishwakarma
/plugin install vishwakarma@vishwakarma
```

This registers the repo as a plugin source, giving you `vishwakarma doctor` and future update notifications.

## Then ask for what you want

```text
Build a pricing page with three tiers.
```

The agent loads the relevant skills, ranks the content before styling anything, resolves values to tokens, checks its colour choices arithmetically rather than by eye, designs the empty and loading states, and runs a critique pass before telling you it is done.
