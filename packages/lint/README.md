# @vishwakarma/lint

Shareable lint rules that enforce design-system adherence in source code.

## Install

```bash
pnpm add @vishwakarma/lint
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/vishwakarma-dev/vishwakarma#readme). This package's
reference is under `docs/packages/lint`.
