# @vishwakarma/theme

Runtime theme engine: flash-free theme switching, density and contrast modes, multi-brand support.

## Install

```bash
pnpm add @vishwakarma/theme
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/yogvidwankhede/vishwakarma#readme). This package's
reference is under `docs/packages/theme`.
