# @vishwakarma/tailwind

Tailwind CSS v4 preset generated from Vishwakarma design tokens.

## Install

```bash
pnpm add @vishwakarma/tailwind
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/vishwakarma-dev/vishwakarma#readme). This package's
reference is under `docs/packages/tailwind`.
