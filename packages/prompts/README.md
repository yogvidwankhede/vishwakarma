# @vishwakarma/prompts

Composable prompt library for frontend generation, review, and refactoring.

## Install

```bash
pnpm add @vishwakarma/prompts
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/vishwakarma-dev/vishwakarma#readme). This package's
reference is under `docs/packages/prompts`.
