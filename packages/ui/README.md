# @vishwakarma/ui

Styled React 19 component library built on Vishwakarma primitives and tokens.

## Install

```bash
pnpm add @vishwakarma/ui
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/vishwakarma-dev/vishwakarma#readme). This package's
reference is under `docs/packages/ui`.
