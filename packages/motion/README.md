# @vishwakarma/motion

Motion primitives implementing the Vishwakarma Motion Grammar, with reduced-motion built in.

## Install

```bash
pnpm add @vishwakarma/motion
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/vishwakarma-dev/vishwakarma#readme). This package's
reference is under `docs/packages/motion`.
