# @vishwakarma/scroll

Scroll experiences: reveals, scroll-linked animation, pinned sequences, and parallax that degrades safely.

## Install

```bash
pnpm add @vishwakarma/scroll
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/yogvidwankhede/vishwakarma#readme). This package's
reference is under `docs/packages/scroll`.
