# @vishwakarma/skills

The Vishwakarma skill catalog and the VSM manifest format, schema, and validator.

## Install

```bash
pnpm add @vishwakarma/skills
```

Full documentation lives at [the Vishwakarma docs](https://github.com/yogvidwankhede/vishwakarma#readme). This package's
reference is under `docs/packages/skills`.
