# @vishwakarma/primitives

Headless, accessibility-first React primitives implementing the ARIA authoring patterns.

## Install

```bash
pnpm add @vishwakarma/primitives
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/yogvidwankhede/vishwakarma#readme). This package's
reference is under `docs/packages/primitives`.
