# @vishwakarma/tokens

Design token schema, the default token set, and transforms to CSS, Tailwind, and TypeScript.

## Install

```bash
pnpm add @vishwakarma/tokens
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/yogvidwankhede/vishwakarma#readme). This package's
reference is under `docs/packages/tokens`.
