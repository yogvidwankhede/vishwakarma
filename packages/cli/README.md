# @vishwakarma/cli

The Vishwakarma CLI: install skills into any agent, add components, generate themes, and audit output.

## Install

```bash
pnpm add @vishwakarma/cli
```

## Documentation

Full documentation lives at [the Vishwakarma docs](https://github.com/vishwakarma-dev/vishwakarma#readme). This package's
reference is under `docs/packages/cli`.
