# @vishwakarma/audit

Static and runtime auditors that evaluate generated UI against a Design Contract.

## Install

```bash
pnpm add @vishwakarma/audit
```

Full documentation lives at [the Vishwakarma docs](https://github.com/yogvidwankhede/vishwakarma#readme). This package's
reference is under `docs/packages/audit`.
